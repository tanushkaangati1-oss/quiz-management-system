# Quiz Management System

A Python-based interactive quiz application that allows users to attempt randomized questions, track their performance, and receive topic-wise analysis.

## Features

- Randomly selects questions from a question bank
- Allows users to choose the number of questions
- Provides multiple-choice questions
- Includes a time limit for each question
- Validates user input
- Calculates the final score
- Reviews incorrectly answered questions
- Tracks question attempts and failure counts
- Provides topic-wise performance statistics
- Stores questions and performance data in JSON format

## Technologies Used

- Python
- JSON
- Random module
- Signal module

## Topics Covered

The question bank currently includes:

- Data Structures
- Algorithms
- Computer Networks
- Databases
